# 🔧 РЕШЕНИЕ: Localhost не устанавливает соединение

## ✅ ОТВЕТ: Используйте порт 8081 вместо 8080

### Проблема:
Порт **8080** занят другим сервисом на вашей системе.

### Решение:
Сервер запущен и работает на порту **8081**.

---

## 🌐 ПРАВИЛЬНЫЕ URL:

### ✅ Откройте эти адреса:

**Тестовая страница (рекомендуется):**
```
http://localhost:8081/test
```

**Основное приложение:**
```
http://localhost:8081
```

**Проверка здоровья:**
```
http://localhost:8081/health
```

**API данных игрока:**
```
http://localhost:8081/api/player
```

---

## ❌ НЕ используйте:

```
http://localhost:8080  ❌ - Занят другим сервисом
```

---

## 🔍 Диагностика:

Если не работает, проверьте:

### 1. Сервер запущен?
```bash
ps aux | grep webapp_server
```

Должно быть:
```
python3 -u webapp_server.py
```

### 2. Порт 8081 доступен?
```bash
curl http://localhost:8081/health
```

Должен вернуть:
```json
{"status": "ok", "service": "termux-rpg-miniapp", "version": "1.0.0"}
```

### 3. Перезапуск сервера:
```bash
pkill -f webapp_server.py
./run_webapp.sh
```

## 🚀 Что занимает порт 8080?

На вашей системе порт 8080 занят процессом **BaseHTTP** (вероятно, другой Python сервер или ttyd).

Проверить можно так:
```bash
curl -I http://localhost:8080
```

Вернёт:
```
HTTP/1.0 302 Found
Server: BaseHTTP/0.6 Python/3.11.2
Location: /login
```

Это НЕ наш сервер. Наш сервер на **8081**.

---

## 💡 Если хотите освободить 8080:

**Внимание:** Это может остановить другие сервисы!

```bash
# Найти процесс
lsof -ti:8080

# Убить процесс (ОСТОРОЖНО!)
sudo kill -9 $(lsof -ti:8080)

# Перезапустить наш сервер на 8080
export PORT=8080
./run_webapp.sh
```

**Но рекомендуется просто использовать 8081!**
