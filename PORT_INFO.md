## ⚙️ Изменение порта

Если хотите использовать другой порт:

```bash
# Остановить сервер
pkill -f webapp_server.py

# Запустить на другом порту (например, 9000)
export PORT=9000
source venv/bin/activate
python3 webapp_server.py
```

Или отредактируйте `run_webapp.sh` и измените строку:
```bash
export PORT=9000  # Ваш порт
```
