## 🎨 Особенности дизайна:

### ✨ Адаптивность
- Автоматически подстраивается под размер экрана
- Оптимизирован для мобильных устройств
- Работает на любом браузере

### 🎯 Интерактивность
- Плавные анимации при переходах
- Прогресс-бары с анимацией заполнения
- Кликабельные элементы с эффектом нажатия
- Модальные окна для деталей

- Современный градиентный дизайн
- Цветовое кодирование (HP - красный, Мана - синий)
- Эмодзи для визуальной привлекательности
- Карточки с тенями для глубины

## 🚀 Как протестировать:

### 1. Откройте в браузере:
```
http://localhost:8888
```

### 2. Протестируйте функционал:

✅ **Профиль**
- Посмотрите статистику персонажа
- Нажмите "Отдохнуть" (работает только в деревне)

✅ **Карта**
- Кликните на "Тёмный лес"
- Вернитесь в профиль - локация изменилась!

✅ **Бой**
- Выберите Гоблина или Волка
- Нажмите "Атака" несколько раз
- Наблюдайте за изменением HP в реальном времени
- Победите врага и получите награды!

✅ **Инвентарь**
- Переключайтесь между вкладками
- Просматривайте предметы

✅ **Магазин**
- Просмотрите доступные товары
- (Покупка в разработке)

## 📱 Для открытия в Telegram:

1. Установите ngrok: https://ngrok.com/download

2. Запустите:
```bash
ngrok http 8888
```

3. Скопируйте HTTPS URL

4. Обновите `.env`:
```env
WEBAPP_URL=https://your-ngrok-url.ngrok.io
```

5. Запустите бота и используйте `/webapp`
